## Dados Brutos e Reprodutibilidade

Devido ao grande volume de dados e às limitações de armazenamento de arquivos grandes em repositórios padrão do GitHub, a base de dados bruta não foi incluída diretamente neste repositório. 

Para reproduzir os resultados ou executar o pipeline completo, a base original deve ser baixada diretamente do repositório público:
- **Fonte:** Kaggle - ENEM 2023 Dataset
- **Link de Acesso:** [Kaggle ENEM 2023](https://www.kaggle.com/datasets/carlosmatos97/enem-2023-dataset/data)

*Nota de execução: Após o download, certifique-se de salvar os arquivos na pasta apropriada `dados` para que os caminhos de leitura funcionem corretamente.*
